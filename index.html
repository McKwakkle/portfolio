Constructionline and Facilitiesline

Full Stack Developer - Contract

Built a multi-variable interactive pricing configurator for Constructionline and Facilitiesline, deployed across three separate product pages. The tool guides users through selecting their turnover band, membership status and SSIP certification, dynamically calculating and displaying the correct price from hundreds of possible combinations, entirely client side with no page reloads. Each of the silver and gold pricing cards also features an independent SSIP discount toggle, requiring careful state management across multiple simultaneous inputs. Also developed the expandable full-plan comparison matrix displayed beneath the pricing cards. The component was architected to be reusable and configurable across different product lines, each with different pricing data sets and input variations.

Marketo Form Redirect System

Full Stack Developer - Contract

Designed and implemented a custom Marketo form redirect solution across the Constructionline and Facilitiesline platforms, deployed on multiple pages site-wide. Taking Marketo's base redirect code as a starting point, I modified and extended it to integrate seamlessly with WordPress and Advanced Custom Fields, allowing the marketing team to configure form redirect URL's directly from the page editor with no developer involvement required. The Obelix Crawl Method

Internal Tool - PHP

A PHP tool built to solve a real workplace problem, auditing large websites for specific words, phrases, CSS selectors, or regex patterns across hundreds of pages. Built after identifying that existing tools like Screaming Frog didn't fully meet the need for content-level keyword searching during a company rebrand. Crawls up to 500 pages with polite rate limiting, provides live progress feedback via session-based polling, and exports results to a styled Excel file using PhpSpreadsheet. Supports three distinct search modes including Unicode-aware plain text matching that avoids partial word matches. Managed with Composer.
